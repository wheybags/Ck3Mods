# What is this repo?
This repo contains a library for loading and editing data files from Crusader Kings III, for the purpose of authoring mods. It also contains a couple of mods made with that system.

## Links
- [Blog post](https://wheybags.com/blog/ck3mods.html) explaining how this all works
- [NoMore](https://steamcommunity.com/sharedfiles/filedetails/?id=3567618623) on the steam workshop - remove nesting from right click menus
- [Eurocentric](https://steamcommunity.com/sharedfiles/filedetails/?id=3562031750) on the steam workshop - display European feudal title tier names everywhere
